## 三個 HTML 站

| 站台 | 給誰看 | 內容 |
|------|--------|------|
| [`docs/learn/`](./learn/index.html) | **完全新手** | 「**我要怎麼自己寫出來？**」——從 `dotnet new mvc` 的空白專案開始，13 章一步步蓋出這套系統。假設讀者連 C# 都不熟 |
| [`docs/tutorial/`](./tutorial/index.html) | **接手開發的人** | 「怎麼做的」——八張循序圖 + 程式碼對照，可點擊、可逐步播放 |
| [`docs/report/`](./report/index.html) | **專題報告評審** | 「做了什麼」——製作動機、系統簡介、功能描述、使用說明 + 實際畫面截圖 |

三個站都是純 HTML，直接用瀏覽器開檔案即可，不需要啟動網站或安裝任何東西。

**該從哪一個開始？**

- 沒寫過 ASP.NET Core MVC → 先走完 [`docs/learn/`](./learn/index.html)，再回來看其他文件。
- 已經懂 MVC，要接手這個專案 → 直接看 [`docs/tutorial/`](./tutorial/index.html) 與 [08-程式碼閱讀指南](./08-程式碼閱讀指南.md)。

## 文件維護原則

1. 程式碼有變動時，**對應文件必須同步更新**。
2. 新增 Entity / Service 時，請更新 `03-資料模型.md` 與 `07-專案結構說明.md`。
3. 修改流程時，請更新 `04-請假與簽核流程.md`。
4. 完成一個 Phase 時，請更新 `05-開發階段與里程碑.md` 的進度標記。
