## 2. 每個資料夾的角色

### Controllers/
- 對應 URL 路由：`/Home/Index` → `HomeController.Index()`
- 每個 Controller 一個檔案，例如：
  - `HomeController` — 首頁
  - `AccountController` — 登入登出
  - `Admin/UsersController` — 帳號管理（路由 /Admin/Users）

### Models/Entities/
- 一個 .cs 檔對應一張資料表
- 純資料定義，不寫商業邏輯
- 可加 `[Required]`、`[StringLength]` 等驗證屬性

### Models/ViewModels/
- 給 View 綁定用（不直接用 Entity 是為了：1. 隔離資料庫結構；2. 加表單驗證；3. 合併多個 Entity）
- 例如：`LoginViewModel` 含 Username/Password；`UserCreateViewModel` 含 SelectedRoleIds[]

### Models/Enums/
- 純 enum 定義，多個地方共用
- 例如：`UserRole`、`LeaveStatus`、`ApprovalDecision`

### Data/
- `AppDbContext`：EF Core 連線進入點
- `SeedData`：應用程式啟動時把預設資料寫進空資料庫

### Services/
- 商業邏輯集中地。Controllers 不直接操作 DB，而是呼叫這裡的服務。
- 範例：
  - `IAuthService` — 登入登出
  - `IPasswordHasher` — BCrypt 密碼雜湊
  - `LeaveCalculator` — 算時數
  - `ApprovalRouter` — 派送簽核關卡
  - `IAbsenceRecordService` / `AbsenceRecordService` — 曠課紀錄 CRUD 與查詢（Phase 6）
  - `NotificationService` — 發通知

### LeaveSystem.Tests/
- 測試專案（xUnit），建議用來落地 TDD。
- Phase 3 目前已加入：`Services/LeaveCalculatorTests.cs`。
- Phase 6 已加入：`Services/AbsenceRecordServiceTests.cs` 與 `Helpers/AbsenceRecordTestScenario.cs`（測試資料工廠，內含 2 班期 × 2 學員 + 4 筆已存在紀錄）。
- 慣例：先寫測試案例（Red）→ 再補實作（Green）→ 最後整理（Refactor）。

### Migrations/
- EF Core 自動產生的「資料庫變更歷史」
- **絕對不要手改**！要改 schema 請改 Entity 然後 `dotnet ef migrations add 名稱`

### Views/
- Razor 視圖（.cshtml）
- 與 Controller 名稱對應：`HomeController.Index` → `Views/Home/Index.cshtml`
- `Shared/_Layout.cshtml` 是共用樣板

### wwwroot/
- 直接給瀏覽器存取的靜態檔
- `css/site.css`、`js/site.js`、`lib/bootstrap/*` 等

## 3. 命名慣例

| 類型 | 命名 | 範例 |
|------|------|------|
| 類別、屬性 | PascalCase | `UserAccount`、`DisplayName` |
| 區域變數 | camelCase | `var totalHours = ...` |
| 介面 | I 開頭 | `IAuthService` |
| 服務實作 | 介面去掉 I + 實作技術 | `BcryptPasswordHasher` |
| ViewModel | XxxViewModel | `LoginViewModel` |
| 控制器 | XxxController | `AccountController` |

## 4. 初學者該優先讀哪些檔？

依以下順序：

1. **`Program.cs`** — 看應用程式怎麼啟動
2. **`Data/AppDbContext.cs`** — 看資料表結構
3. **挑一個 Entity（如 `UserAccount.cs`）** — 看欄位定義
4. **`HomeController.Index`** — 看一次最簡單的請求
5. **`Views/Home/Index.cshtml`** — 看視圖怎麼寫
6. （Phase 1 後）**`AccountController` + `AuthService`** — 看登入流程
