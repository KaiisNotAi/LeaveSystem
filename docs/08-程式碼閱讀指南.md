# 08 — 程式碼閱讀指南

本文件用「追蹤一次請求」的方式，帶您熟悉整個程式碼。

## 1. 建議閱讀順序

| 順序 | 檔案 | 為什麼先讀這個 |
|------|------|---------------|
| 1 | `Program.cs` | 應用程式入口，理解整體啟動流程 |
| 2 | `appsettings.json` | 看連線字串等設定 |
| 3 | `Data/AppDbContext.cs` | 理解資料庫結構 |
| 4 | `Models/Entities/UserAccount.cs` | 看一個典型 Entity |
| 5 | `Models/Enums/UserRole.cs` | 看 enum 怎麼設計 |
| 6 | `Controllers/HomeController.cs` | 最簡單的 Controller |
| 7 | `Views/Home/Index.cshtml` | 最簡單的 View |
| 8 | （Phase 1 後）`AccountController` + `AuthService` | 真實的商業邏輯 |

## 2. 追蹤範例：開啟首頁時發生什麼

```
[瀏覽器] 輸入 https://localhost:xxxx/
   │
   ▼
[Kestrel Web Server] 收到 HTTP 請求
   │
   ▼
[Program.cs 中介軟體管線]
   1. UseRouting       ← 解析 URL「/」對應到 HomeController.Index
   2. UseAuthorization ← 檢查 [Authorize]（HomeController.Index 沒有，通過）
   3. MapControllerRoute ← 把請求交給 HomeController
   │
   ▼
[HomeController.Index()]
   return View();   ← 找 Views/Home/Index.cshtml
   │
   ▼
[Razor 引擎]
   1. 讀 Views/Home/Index.cshtml
   2. 讀 _ViewStart.cshtml（設定 Layout = "_Layout"）
   3. 讀 Views/Shared/_Layout.cshtml（包住內容）
   4. 渲染成完整 HTML
   │
   ▼
[瀏覽器] 收到 HTML 顯示
```

## 3. 追蹤範例：學員登入（Phase 1 完成後）

```
[瀏覽器] 點「登入」連結 → GET /Account/Login
   │
   ▼
[AccountController.Login(string returnUrl)]
   返回 Views/Account/Login.cshtml（空白表單）
   │
   ▼
[使用者填好帳號密碼點送出]
   → POST /Account/Login（夾帶 LoginViewModel）
   │
   ▼
[AccountController.Login(LoginViewModel model)]
   1. 檢查 ModelState.IsValid（驗證屬性檢查必填、長度等）
   2. var user = await _authService.ValidateAsync(model.Username, model.Password)
		│
		▼
   [AuthService.ValidateAsync]
	  1. 從 DbContext 撈 UserAccount
	  2. 用 BCrypt.Verify 比對密碼
	  3. 回傳 user 或 null
		│
   3. 如果 user == null → 顯示錯誤訊息，重新顯示登入頁
   4. 否則 await _authService.SignInAsync(HttpContext, user)
		│
		▼
   [AuthService.SignInAsync]
	  1. 載入 user 的 UserRoles + Roles
	  2. 建立 ClaimsPrincipal（含 NameIdentifier、Name、每個 Role）
	  3. await HttpContext.SignInAsync(...)（寫 Cookie）
		│
   5. RedirectToAction("Index", "Home")
   │
   ▼
[瀏覽器] 收到 302 + Set-Cookie，跳轉首頁
   │
   ▼
[後續每次請求] 自動帶 Cookie，UseAuthentication 還原 User
```

## 4. 怎麼新增一個功能？

以「行政查看所有班期」為例（Phase 2 場景）：

```
1. 確認需求：要列出班期清單，含名稱、起訖日、學員數

2. ViewModel 設計：CohortListItemViewModel { Name, StartDate, EndDate, StudentCount }

3. Controller：
   public class CohortController : Controller {
	   private readonly AppDbContext _db;
	   public CohortController(AppDbContext db) { _db = db; }

	   [Authorize(Roles = "Admin,Staff")]
	   public async Task<IActionResult> Index() {
		   var list = await _db.Cohorts
			   .Select(c => new CohortListItemViewModel { ... })
			   .ToListAsync();
		   return View(list);
	   }
   }

4. View：Views/Cohort/Index.cshtml
   @model List<CohortListItemViewModel>
   <table>...</table>

5. 加導覽列連結：Views/Shared/_Layout.cshtml
   @if (User.IsInRole("Admin") || User.IsInRole("Staff")) { 班期管理 連結 }
```

## 5. 除錯技巧

### 5.1 中斷點（Breakpoint）

按 F9 在程式碼行設中斷點，F5 啟動偵錯。執行到該行會暫停，可看：
- **變數值**：滑鼠停在變數上
- **呼叫堆疊**：誰呼叫誰
- **即時運算式**：在「即時運算」視窗輸入 C# 運算式

### 5.2 觀察 EF Core SQL

在 `appsettings.Development.json` 加：
```json
"Logging": {
  "LogLevel": {
	"Microsoft.EntityFrameworkCore.Database.Command": "Information"
  }
}
```

啟動後在「輸出」視窗就能看 EF Core 實際送出的 SQL。

### 5.3 看 SSMS 撈資料驗證

寫完 `_db.SaveChanges()` 後，到 SSMS 開新查詢：
```sql
USE LeaveSystem;
SELECT * FROM UserAccounts;
```

確認資料真的進去了。
