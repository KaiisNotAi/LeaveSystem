共 11 個實體，分為 身分、組織/規則、 交易資料、通知/稽核 四大群組（以背景色區分）。 PK 主鍵、FK 外鍵；連線標記 1 或 N。

🔑 = 主鍵 PK FK 藍色斜體 = 外鍵 │ = 「1」端 >─ = 「N」端（鴉爪） 橘色虛線框 = 多對多橋接表 灰色虛線 = 選用 / nullable 關聯

編號關聯基數說明
R1+R2UserAccount ↔ RoleN : M透過 UserRole 橋接（一位使用者可有多個角色）
R3Cohort → UserAccount1 : N一個班期可含多位學員
R4Cohort ↔ UserAccount1 : 1 × 3班期同時參照 3 位簽核人（Tutor / Chief / Director）
R5UserAccount → LeaveRequest1 : N一位學員可送多張請假單
R6LeaveType → LeaveRequest1 : N一種假別對應多筆申請
R7LeaveRequest → LeaveRequestStep1 : N一張單依規則產生 1~3 個簽核步驟
R8UserAccount → LeaveRequestStep1 : N簽核人 approver（未簽時為 NULL）
R9UserAccount → AbsenceRecord1 : N學員被登錄多筆曠課
R10UserAccount → AbsenceRecord1 : NCreatedByUserId 記錄行政登錄者
R11UserAccount → Notification1 : N一位使用者可收多則通知
R12UserAccount → AuditLog1 : N操作稽核（可 NULL 表匿名 / 系統）
