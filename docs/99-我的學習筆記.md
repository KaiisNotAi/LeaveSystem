**新學到的概念（用自己的話寫）：**

- **Claim**：對使用者身份的一項聲明（像護照上的一行資訊）
- **ClaimsPrincipal**：一捆 Claims，代表完整登入身份
- **Cookie 認證**：把 Claims 加密放 Cookie，每次請求帶回來還原
- **Entity Framework Core**：把 C# 類別與資料表對應的 ORM 工具
- **DbContext**：資料庫進入點，每個 DbSet 是一張表
- **LINQ**：用 C# 寫查詢，EF Core 自動翻成 SQL

## 🗒️ 概念速查（自己整理）

### 一個 HTTP 請求的生命週期（簡化版）

```
[瀏覽器發 HTTP 請求]
		↓
Program.cs 中介軟體管線
  UseRouting        → 解析 URL 對應到哪個 Controller
  UseAuthentication → 從 Cookie 還原 ClaimsPrincipal
  UseAuthorization  → 檢查 [Authorize] 等規則
		↓
Controller Action 執行
		↓
回傳 View / JSON / Redirect
		↓
[瀏覽器顯示結果]
```

### 登入流程簡化版

```
表單送出 → ModelState 驗證 → AuthService.ValidateAsync
								   ↓
						  DbContext 查使用者 + Roles
								   ↓
						  BCrypt 比對密碼雜湊
								   ↓
						  建 ClaimsPrincipal
								   ↓
						  context.SignInAsync 寫 Cookie
								   ↓
								Redirect 首頁
```

### LINQ 常用方法（補一個我用得到時的提醒）

| 方法 | 一句話 |
|------|--------|
| `.First()` | 取第一個（空集合會炸）|
| `.FirstOrDefault()` | 取第一個（空集合回 null）|
| `.Any()` | 是否有元素（比 Count > 0 快）|
| `.Where(...)` | 篩選 |
| `.Include(...)` | 連同關聯資料一起撈 |
| `.ToListAsync()` | 執行查詢並轉成 List |
