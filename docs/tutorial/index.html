Sequence Diagrams

一次看懂：每個 Controller、Service、方法是怎麼串起來的

docs/08-程式碼閱讀指南.md 用文字箭頭說明「請求會經過哪些檔案」， 但看不出呼叫的是哪個方法、參數是什麼、在第幾行、回傳什麼。 本站把八條主要流程各畫成一張循序圖，圖上每一支箭頭都標著真實的方法簽章， 點下去就會跳到對應的程式碼節錄與 檔案:行號。

📘 還沒學過 ASP.NET Core MVC？本站會太跳。
本站假設你已經懂 MVC、EF Core、DI 這些觀念，只是不熟這個專案。 如果你是從零開始，請先走 從零開始學 ASP.NET Core MVC—— 那是一本從空白專案一步步蓋出這整套系統的入門書。走完再回來，這八張圖會非常好讀。

怎麼使用

操作效果
滑鼠移過箭頭 / 卡片圖與程式碼互相高亮，其他步驟淡出
點擊箭頭跳到下方對應的程式碼卡片
▶ 逐步播放依序點亮步驟 1…N，像跟著呼叫堆疊走一次
← →上一步 / 下一步
Space播放 / 暫停
Esc取消高亮
F / Home全螢幕 / 回目錄

圖例：lifeline 的顏色代表哪一層

瀏覽器 / 使用者 中介軟體管線（Routing / Authentication / Authorization） Controller（Controllers/） Service（Services/，商業規則） EF Core / AppDbContext SQL Server 外部（MailKit / 檔案系統）

實線箭頭 ⟶ 是呼叫，虛線箭頭 ⇠ 是回傳。分層順序固定由左到右， 所以箭頭愈往右，代表離資料庫愈近。
