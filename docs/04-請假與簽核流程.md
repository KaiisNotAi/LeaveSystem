# 04 — 請假與簽核流程

## 1. LeaveRequest 狀態機

```
	   建立草稿
		   │
		   ▼
	  ┌────────┐    送出      ┌──────────┐
	  │ Draft  │─────────────→│ Pending  │
	  └────────┘              │（簽核中）│
							  └────┬─────┘
								   │
			  ┌────────────────────┼────────────────────┐
			  │                    │                    │
			  ▼                    ▼                    ▼
		 ┌────────┐         ┌──────────┐         ┌────────────┐
		 │Approved│         │ Rejected │         │ Cancelled  │
		 │(全核准)│         │(任一駁回)│         │(學員撤銷)  │
		 └────────┘         └──────────┘         └────────────┘
```

## 2. 簽核派送邏輯（ApprovalRouter）

當學員按下「送出」時：

```
1. 計算請假總時數 totalHours = LeaveCalculator.Calculate(StartAt, EndAt)

2. 查 ApprovalRule，找到第一筆滿足：
   MinHours <= totalHours AND (MaxHours IS NULL OR totalHours <= MaxHours)

3. 從規則的 RequiredRoles JSON 解析出角色清單：
   ["Tutor"] / ["Tutor","SectionChief"] / ["Tutor","SectionChief","BranchDirector"]

4. 為每個角色建立一筆 LeaveRequestStep：
   Level = 1, 2, 3...
   ApproverRole = 角色字串
   Decision = Pending

5. 設定 LeaveRequest:
   Status = Pending
   CurrentLevel = 1
```

## 3. 單關簽核處理

當第 N 關簽核人點「核准」或「駁回」：

### 3.1 核准

```
更新此 Step:
   Decision = Approved
   ApproverUserId = 當前使用者
   Comment = 意見
   DecidedAt = 現在

判斷是否還有下一關：
   IF 還有 Step.Level > CurrentLevel
	   LeaveRequest.CurrentLevel++
	   通知下一關簽核人
   ELSE
	   LeaveRequest.Status = Approved
	   通知申請人「已核准」
```

### 3.2 駁回

```
更新此 Step:
   Decision = Rejected
   ApproverUserId = 當前使用者
   Comment = 駁回原因（必填）
   DecidedAt = 現在

LeaveRequest.Status = Rejected
通知申請人「被駁回」+ 原因
（後續關卡的 Step 保持 Pending，不再處理）
```

## 4. 誰能看到誰的待辦？

| 角色 | 看得到的待辦 |
|------|-------------|
| 導師 | 班期所屬學員、CurrentLevel=1 且該關 Role=Tutor 的單 |
| 科長 | 班期所屬、CurrentLevel=2 且該關 Role=SectionChief 的單 |
| 分署長 | 同上但 Role=BranchDirector |

關鍵：**Level 必須等於 CurrentLevel**，否則前一關還沒簽，下一關不會看到。

## 5. 班期請假上限檢查

學員送出申請前：

```
1. 從 Cohort 取出 LeaveLimitHours
2. 累計該學員此班期所有 Status=Approved 的 LeaveRequest.TotalHours
3. 加上本次申請的 totalHours
4. IF 累計 > LeaveLimitHours
	   拒絕送出，顯示「將超過班期請假上限 X 小時」
```

## 6. 時數計算規則（LeaveCalculator）

每日上課時段：
- 上午：08:00 ~ 12:00（4 小時）
- 下午：13:00 ~ 17:00（4 小時）
- 午休 12:00 ~ 13:00 不計

### 範例

| 區間 | 計算 |
|------|------|
| 6/9 08:00 ~ 6/9 09:00 | 1 小時 |
| 6/9 11:00 ~ 6/9 14:00 | 1（11-12）+ 1（13-14）= 2 小時 |
| 6/9 08:00 ~ 6/9 17:00 | 4 + 4 = 8 小時（一整天） |
| 6/9 08:00 ~ 6/10 17:00 | 8 + 8 = 16 小時 |
| 6/9 13:00 ~ 6/10 12:00 | 4 + 4 = 8 小時 |

最小單位 1 小時，學員下拉選單只能選整點時間。
