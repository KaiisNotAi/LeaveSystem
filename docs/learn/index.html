ASP.NET CORE MVC · 從空白專案開始

用「學生請假系統」當教材，從零學會 ASP.NET Core MVC

這本書要帶你做什麼 你會從一個完全空白的專案開始（就是 dotnet new mvc 產生的那個）， 一章一章把功能疊上去，最後蓋出一套跟 E:\伺服器程式\LeaveSystem 結構相同的請假管理系統：帳號登入、三級簽核、報表統計、曠課紀錄、Email 通知、Excel 匯出。

本書假設你連 C# 都不熟。第 1 章會把後面用得到的 C# 語法補齊， 但不會把 C# 從頭教到尾——只教「蓋這個系統會用到的那些」。

為什麼要自己重蓋一遍，不直接讀現成的程式碼？

因為讀懂跟寫得出來是兩回事。直接翻 3,800 行的現成專案， 你會看到「一堆東西已經在那裡」，但不知道它們是為了解決什麼問題才被加進去的。

本書的順序刻意跟專案的開發順序一致：每一章都先讓你遇到一個具體的麻煩， 再引進解決它的觀念。例如你會先把業務規則寫在 Controller 裡， 親身體會它變得多難測試，第 9 章才引進 Service 層。

課程地圖

PART 1 準備與基礎

把工具裝好、把 C# 補到夠用、讓第一個網頁跑起來。

00 開始之前 你會做出什麼、要裝哪些東西、怎麼用這本書 01 C# 夠用就好 變數、class、集合、LINQ、介面、async — 只講後面用得到的 02 第一個網站 dotnet new mvc、每個資料夾是什麼、Program.cs 在做什麼

PART 2 MVC 三個字母

網址怎麼變成方法呼叫、資料怎麼畫到畫面、表單送出後發生什麼事。

03 路由與 Controller 網址 → Controller → Action，以及 IActionResult 的各種回傳 04 View 與 Razor Razor 語法、Layout、把資料從 Controller 帶到畫面 05 表單、繫結與驗證 ViewModel、模型繫結、ModelState、防偽權杖、PRG 模式

PART 3 資料庫

讓資料活過重新啟動。EF Core、Migration、CRUD 四件套、資料表之間的關聯。

06 資料庫與 EF Core Entity、DbContext、連線字串、Migration 是什麼 07 第一個完整 CRUD 做出「假別管理」：新增 / 查詢 / 修改 / 停用 08 關聯資料 使用者、角色、班期：一對多、多對多、Include 與 N+1

PART 4 蓋出真正的系統

業務規則往哪擺、怎麼確定它是對的、怎麼擋住不該進來的人。

09 服務層、DI 與測試 把規則搬出 Controller、依賴注入、寫第一個 xUnit 測試 10 登入與權限 密碼雜湊、Cookie 認證、Claims、[Authorize] 與角色 11 請假與簽核 狀態機、依時數展開 N 關簽核、防止越權簽核 12 收尾與接下來 報表、曠課、通知、匯出的導覽，以及你可以自己加什麼

怎麼開始

  1. 先讀 第 0 章，把 .NET SDK 與資料庫裝好。
  2. 照順序讀。每章都假設你做完了前一章，跳章會卡住。
  3. 每章結尾的檢查點要真的動手做過再勾——那是確認你的專案跟書上一致的方法。
  4. 卡住的時候：先看該章的「⚠️ 常見錯誤」框，八成你遇到的就在裡面。
