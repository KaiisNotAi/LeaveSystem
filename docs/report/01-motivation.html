CHAPTER 01

製作動機

為什麼要做這個系統？從一份紙本假單、一則 LINE 訊息說起， 看看目前流程對學員、導師、行政三方所造成的具體困擾。

1.1 現況：LINE + 紙本假單

某培訓機構目前的請假流程：

學員
→
LINE 通知導師
→
寫紙本假單
→
實體傳遞簽核
→
行政人工輸入表格
→
完成

整條流程有 3 種載體（LINE、紙本、Excel）、4 個關卡、 每個環節都可能延遲或遺失，最終還要花時間對表確認累計時數。

1.2 三方痛點

角色面臨的困擾
學員 🎒 要 LINE 通知導師、寫紙本假單、等簽核、等行政登記、再對表確認時數， 流程冗長，中間狀態完全不透明。
導師 👨‍🏫 LINE 訊息與紙本假單散落各處，同時帶多個班級時容易漏看， 無法快速看累計請假狀況，也難以留下正式簽核意見。
行政（小華） 📋 假單可能遺失、字跡潦草、人工輸入表格費時， 每月統計各學員請假時數與班期上限比對非常吃力。

1.3 導入後：三方 Before / After

❌ 導入前

  • 學員來回 LINE / 紙本 / 電話追蹤進度
  • 導師漏看訊息、無累計視圖
  • 行政手動抄寫、每月夜加班對表
➜

✅ 導入後

  • 學員一站式送單、即時看簽核進度、時數自動累計
  • 簽核人集中待辦、意見留存、班期一目了然
  • 行政不再抄寫、隨時匯出 CSV / Excel 報表

目標 完全取代紙本與 LINE 通報，讓三方在同一平台合作。
