# 03 — 資料模型

本系統共 11 張資料表，由 EF Core Code First 產生。所有 Entity 程式碼位於 `Models/Entities/`。

## 1. ER 圖（簡化文字版）

## 2. 資料表詳細

### 2.1 UserAccount（使用者帳號）

| 欄位 | 型別 | 說明 |
|------|------|------|
| Id | int (PK) | 自動編號 |
| Username | nvarchar(50) UNIQUE | 登入帳號 |
| PasswordHash | nvarchar(200) | BCrypt 雜湊 |
| DisplayName | nvarchar(50) | 顯示名稱 |
| Email | nvarchar(100) | Email |
| CohortId | int FK→Cohort | 所屬班期（學員才有值） |
| IsActive | bit | 是否啟用 |
| CreatedAt / UpdatedAt | datetime | 時戳 |

### 2.2 Role（角色字典）

| 欄位 | 型別 | 說明 |
|------|------|------|
| Id | int (PK) | 對應 enum 數值 |
| Name | nvarchar(50) UNIQUE | 英文名（如 "Admin"） |
| DisplayName | nvarchar(50) | 中文名（如「系統管理員」） |

種子資料：6 筆固定資料。

### 2.3 UserRole（使用者-角色 多對多）

|------|------|------|
| UserId | int (PK + FK) | 複合主鍵 |
| RoleId | int (PK + FK) | 複合主鍵 |

## 3. 重要設計決策

1. **decimal(6,2)** 用於時數類欄位：最多 9999.99，足夠表示一個班期的請假時數，又不會浪費空間。
2. **唯一索引 Username 與 Code**：避免重複資料。
3. **OnDelete(Restrict)** 用於關鍵 FK：防止意外連動刪除（例：班期被學員引用就不能刪）。
4. **OnDelete(Cascade)** 用於 LeaveRequestStep：刪請假單時連同步驟一起清掉，邏輯合理。
5. **角色用獨立 Role 表**：日後新增角色不用改 enum，雖然當前 enum 與表並存看似冗餘，但對學習者更直觀。
