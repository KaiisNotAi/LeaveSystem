功能描述

3.1 帳號管理與登入

安全機制

  • 密碼以 BCrypt 加鹽雜湊（不可逆）
  • Cookie 認證：HttpOnly、8 小時、SlidingExpiration
  • 角色授權：[Authorize(Roles=...)] 標記
  • 非授權存取 → 導向 /Account/AccessDenied

行政後台建帳號

  • 建立、編輯、重設密碼、停用/啟用
  • 可指派角色與所屬班期
  • 預設管理員：Admin / Admin@123

3.2 班期 · 假別 · 簽核規則

班期 Cohort

  • 設定總上課時數（例：900 小時）
  • 設定請假上限百分比（預設 10%）
  • 指派導師 / 科長 / 分署長

假別 LeaveType

  • 病假、事假、喪假、公假…可自訂
  • 行政端增刪改查

簽核規則 ApprovalRule

  • 依請假時數自動判斷簽核層級
  • 規則可由 Admin 調整門檻

3.3 學員請假申請

送單流程

  1. 選擇假別（下拉）
  2. 選擇 日期 + 上課時段（最小 1 小時）
  3. 填寫請假原因（必填）
  4. 系統自動計算總時數
  5. 系統檢查是否超過班期上限
  6. 送出後即進入 Pending 狀態

💡 系統自動扣除午休 12:00-13:00 與下班時段 17:00 後。

3.3 時數計算規則（LeaveCalculator）

每日上課時段：上午 08:00–12:00（4 小時）+ 下午 13:00–17:00（4 小時）＝ 8 小時 / 日。

請假區間計算過程總時數
6/9 08:00 ~ 09:00純上午 1 小時1 小時
6/9 11:00 ~ 14:001（11–12）＋ 1（13–14）＝ 2（扣午休）2 小時
6/9 08:00 ~ 17:004 ＋ 4 ＝ 8（整天）8 小時
6/9 08:00 ~ 6/10 17:008 ＋ 8 ＝ 16（跨日）16 小時
6/9 13:00 ~ 6/10 12:004 ＋ 4 ＝ 8（跨日跨午休）8 小時

最小單位 1 小時 學員下拉只能選整點 跨午休 / 跨日皆正確處理

3.4 簽核操作頁

簽核人視角

  • /Approvals：待辦清單（依角色 + CurrentLevel 過濾）
  • /Approvals/Details/{id}：單張詳情
  • 核准 / 駁回按鈕；駁回原因必填
  • 已簽過的 Step 顯示歷程與意見

身分驗證

  • 必須是 CurrentLevel 且為該班期該角色指定簽核人
  • 同一 Step 不能重複簽

3.5 紀錄查詢與時數統計

學員視角

  • /Reports：依 狀態 / 假別 / 日期 三條件篩選我的請假
  • /Reports/Summary：各假別累計時數 + 班期上限進度條
  • 統計口徑：僅計 Approved

行政視角

  • /Reports/Admin：班期 × 學員 × 假別 × 年月 彙總
  • 四種篩選條件可組合
  • 學員誤入 → AccessDenied

3.6 曠課紀錄

設計原則

  • 曠課是行政事後登錄的既定事實
  • 不走簽核流程，不影響請假單狀態
  • 時數規則：1~100 小時整數（不接受 0.5）

行政端

  • 依班期 / 學員 / 日期查詢，顯示總時數
  • 只能選擇 Student 角色的使用者

學員端

  • 僅查閱自己；累計時數不受日期篩選影響

3.7 站內通知 + Email

觸發時機（4 事件）

  1. 學員送單 → 通知第一關簽核人
  2. 逐級通過 → 通知下一關簽核人
  3. 全部通過 → 通知申請人「已核准」
  4. 任一駁回 → 通知申請人「被駁回」+ 原因

雙通道

  • 站內通知：導覽列 🔔 未讀徽章、通知中心
  • Email：MailKit；開發用 PickupDirectory，正式可切 SMTP
  • Email 失敗容錯：不影響簽核主流程

3.8 報表匯出（CSV / Excel）

授權範圍

StaffAdmin 專用；學員自查頁不含匯出按鈕。

兩種格式

  • CSV：UTF-8 BOM、RFC 4180 跳脫
  • Excel：ClosedXML 0.105.1，支援單 sheet 與多 sheet

匯出頁 /Admin/Export

  • 班期必選 + 學生（單人或全部）+ 日期起迄
  • 一鍵匯出多 sheet Excel：請假明細 / 曠課明細 / 彙總
  • 或分別下載 CSV
